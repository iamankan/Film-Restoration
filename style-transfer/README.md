# Style transfer

As the dataset has been made by scanning the film negatives and segmenting using Local Resclie Particle Simulator (LRPS) algorithm, we get two modalities, namely X-ray and optical image.

As film negatives are meant to be viewed under visible light, it is important to use the information generated from X-ray to produce a print-quality image, as if the film were viewed by shining visible light through it.

So, just to recap, the data looks like this:
Rendered from CT-Scan            |  Digital image (registered)
:-------------------------:|:-------------------------:
![xray](../data/media/images/volpkg_renderings/jpgs/001_render.jpg)  |  ![digital](../data/media/images/registered/jpgs/001_reg.jpg)

The left one is X-ray modality and the right one is the optical image, generated by shining visible light through it. Although the virtually unwrapping a X-ray based CT-scan generates an image similar to the image on the right, it is not print-quality. There are artifacts produced due to the X-ray, like those vertical stripes. So, basically if we can learn a mapping between the two modalities, given an virtually unwrapped X-ray film negative, we can generate the digital image. We can leverage the deep learning models for learning the mapping.
